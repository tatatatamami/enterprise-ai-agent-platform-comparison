# エンタープライズ AI エージェント基盤 比較資料
## AWS AgentCore vs Microsoft Azure AI Foundry

本資料は、エンタープライズ向け AI エージェント基盤として注目される **AWS AgentCore** と **Microsoft Azure AI Foundry**（以下、Microsoft Foundry）を、証拠ベースの観点から中立的に比較・整理したものです。組織が AI エージェントを効果的に構築・運用し、継続的に改善していくための判断材料として活用いただくことを目的としています。

## Microsoft Azure AI Foundry の主要統合コンポーネント

Microsoft Foundry はエンタープライズ環境との深い統合を前提として設計されています。本資料では以下のコンポーネントとの連携を重点的に評価しています。

| コンポーネント | 役割 |
|---|---|
| **Microsoft Entra ID** | ID・アクセス管理、条件付きアクセス、RBAC |
| **Azure Monitor** | エージェント動作の監視・ログ収集・アラート |
| **Azure AI Search** | エンタープライズデータへの RAG（検索拡張生成） |
| **Microsoft Fabric** | 統合データ分析基盤との連携 |
| **Azure Logic Apps** | ビジネスプロセスとの自動化統合 |
